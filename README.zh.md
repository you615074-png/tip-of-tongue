# tip-of-tongue · 话到嘴边

**在 AI 动手之前，帮你把真正想说的话说出来。**

[English](README.md)

我们和 AI 的所有协作，都建立在 AI 理解我们语言的基础上。但语言是有损耗的，无论中文还是英文。大多数人心里其实知道自己要什么，只是话卡在喉咙里，最后对 AI 说出口的只是一个粗略的近似。AI 只能用最常见的默认值去填补空白，而那恰恰是你不想要的。

常见的建议是“学会写更好的 prompt”。这个 skill 的思路相反：**不是让人变成更好的表达者，而是让 AI 变成更好的倾听者。**

`tip-of-tongue` 是一个 [Agent Skill](https://agentskills.io)。它会察觉你卡住了，帮你把话说出来，并在动手之前和你确认。

## 它怎么工作

先判断你卡在哪，因为不同的卡法需要不同的帮助：

| 卡住的原因 | 典型说法 | skill 怎么做 |
|---|---|---|
| **缺词**：感觉很准，但没有对应的词 | “感觉不对”“太乱了”“要高级一点” | 给出候选词和白话解释：*“你说的乱，是没有重点（层级）、没对齐（对齐），还是东西太多（密度）？”* |
| **能认出来，说不出来**：看到就知道对不对 | “不是这个”“看到了我就知道” | 给 2 到 4 个选项让你挑、给对比让你比，再替你把选择翻译成文字 |
| **还没理顺**：东西都在，但是散的 | 长、绕、前后矛盾 | 把你说的复述回来，点出其中的矛盾，问你哪边优先 |
| **以为不用说**：上下文只在你脑子里 | 很短，缺少给谁、为什么、要避开什么 | 先说出它的默认假设让你纠正，纠正比主动补充容易得多 |

然后它会写一份简短的需求说明：目标、想要的感觉、必须和不能、上下文，以及**原样保留的你自己的话**，问你“是这个意思吗？”。你确认之后它才开始做。

清楚的请求会直接放行。追问已经清楚的东西不是帮忙，是添堵。

## 安装

skill 就是一个文件：[`skills/tip-of-tongue/SKILL.md`](skills/tip-of-tongue/SKILL.md)，采用开放的 Agent Skills 格式，支持 skill 的工具都能用。

**Claude Code**

```bash
git clone https://github.com/OWNER/REPO.git
cp -r REPO/skills/tip-of-tongue ~/.claude/skills/
```

可以自动触发，也可以用 `/tip-of-tongue` 手动调用。

**Codex CLI**

```bash
cp -r REPO/skills/tip-of-tongue ~/.codex/skills/
```

**Claude.ai（网页或 App）**

从 [Releases](../../releases) 下载 `tip-of-tongue.zip`，进入 **Customize → Skills → + → Upload a skill** 上传。上传后默认关闭，需要手动打开。

**其他工具（Cursor、Gemini CLI 等）**

```bash
npx skills add OWNER/REPO
```

## 试一试

新开一个对话，故意说一句模糊的话：

- “帮我把这个页面改得高级一点”
- “帮我写段介绍，感觉要对”
- “这不是我想要的”（在任意结果之后）

如果 skill 生效了，你会先收到几个选项让你挑，而不是直接被改一遍。
